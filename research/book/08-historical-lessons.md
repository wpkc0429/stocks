# 第八章：歷史重大市場事件與投資教訓

研究日期：2026-08-11

## 1. 2008年全球金融海嘯(次貸危機)

**發生了什麼：**
- 成因是寬鬆信貸、放款標準鬆散、次級房貸被大量包裝成證券化商品轉賣全球，加上監管在消費者保護、私募證券化、銀行資本適足率等關鍵領域嚴重不足。
- 當利率上升、房價下跌，違約潮爆發，重壓抵押證券的金融機構相繼倒閉，最終需要政府紓困；連傳統上被視為流動性高的資產(如MBS)也一度賣不出去。

**教訓：**
- 金融創新(證券化)本身會創造新的風險類別，越複雜的產品越需要更嚴謹的監管與盡職調查。
- 警惕「這次不一樣」的房價只漲不跌迷思；分散持有標的、避免過度依賴單一資產類別(房地產)。

## 2. 2000年網路泡沫

**發生了什麼：**
- 1995–2000年間投資人對網路股極度樂觀，Nasdaq五年漲逾五倍，許多公司無獲利甚至無穩定商業模式也被瘋狂追捧，基本面被忽略。
- 泡沫在2000年中破裂，Nasdaq到2002年底重挫逾80%，多數投資人財富腰斬甚至更慘。

**教訓：**
- 「創新不能廢除經濟學基本定律」——再新穎的題材，公司終究要能獲利。
- 分散投資可緩衝單一板塊崩跌的衝擊；牛市與熊市都要保持對基本面的紀律。

## 3. 1998年LTCM(長期資本管理公司)倒閉

**發生了什麼：**
- LTCM由包括諾貝爾獎得主Myron Scholes、Robert Merton在內的頂尖團隊操盤，以Black-Scholes選擇權定價模型為基礎，押注市場價差會「收斂」回歷史關係。
- 1998年8月俄羅斯無預警債務違約、盧布重貶，此為模型訓練用的歷史數據中從未出現的極端事件，市場關係在壓力下全面失效，該基金單月虧損44%。
- 更致命的是槓桿：1998年8月底槓桿約25倍，俄國違約後暴增至50倍，9月第三週更達130倍，最終由14家金融機構在聯準會協調下注資36.5億美元紓困。

**教訓(高槓桿+高度自信量化模型如何失效)：**
- 模型只能基於歷史數據校準，一旦出現「歷史上沒發生過」的尾部風險(黑天鵝)，模型的相關性假設會同時失靈，且往往在最需要模型的時刻失靈。
- 槓桿會把小虧損放大成致命虧損——LTCM的資產虧損其實不算誇張，真正致命的是槓桿倍數暴衝；智力與學術聲望(諾貝爾獎)不能取代對尾部風險與壓力測試的謙卑。
- 「市場保持非理性的時間可能比你能維持償付能力的時間更長」，這正是LTCM教訓的核心。

## 4. 2022年加密貨幣崩盤：Terra/LUNA與FTX

**發生了什麼：**
- Terra生態的演算法穩定幣UST靠與LUNA的兌換機制維持1美元錨定，並透過Anchor協議提供不合理的高收益吸引存款；2022年5月UST脫錨引發擠兌，三天內LUNA與UST雙雙歸零，蒸發約500億美元市值，單月加密市場損失約180億美元。
- 同年11月，全球第二大交易所FTX爆出客戶資產與自家關係企業Alameda挪用、1:1保證金並未落實，單日湧現逾50億美元提領潮而破產，暴露出交易所缺乏透明度與審計的結構性弱點。

**教訓：**
- 「演算法穩定幣」的錨定機制在極端擠兌下可能瞬間崩潰，過高且不可持續的收益率(如Anchor的高利率)本身就是風險警訊。
- 資產若存放在缺乏獨立託管、審計與監管的中心化平台，就承擔交易對手風險；「不是你的私鑰，就不是你的幣」在FTX事件中得到印證。

## 5. 共通模式與給一般投資人的警示原則

綜合以上四個案例，可歸納出重複出現的模式：

- **槓桿放大一切**：無論是2008年的高槓桿房貸證券化、LTCM的25倍到130倍槓桿，槓桿在順風時放大獲利，在逆風時同樣放大虧損速度，且常伴隨強制平倉的連鎖反應。
- **流動性錯配**：用短期、可隨時贖回的資金(銀行擠兌、UST贖回、FTX提領)去支撐長期或非流動性資產，一旦信心動搖就會發生「擠兌」，這在2008年的影子銀行、LTCM的部位、Terra的UST上一再重演。
- **群體心理與過度自信**：網路泡沫的非理性追捧、LTCM團隊對自身模型的高度自信、加密貨幣牛市中對高收益的盲目追逐，都顯示情緒與從眾行為會系統性地掩蓋風險。
- **監管與透明度缺失**：2008年的證券化商品監管落後、FTX缺乏第三方審計與資產隔離，說明缺乏外部監督時，內部誘因常會走向風險累積而非風險控管。

**給一般投資人的具體警示原則：**
1. 對「保證高報酬」或「這次不一樣」的敘事保持懷疑，尤其當收益率遠高於市場合理水準時。
2. 避免使用超出自身承受能力的槓桿，記住槓桿會把「暫時虧損」變成「強制出場」。
3. 分散配置，不把資產集中在單一資產類別、單一平台或單一交易對手。
4. 了解自己持有資產的流動性特性，尤其在市場壓力下流動性可能瞬間消失。
5. 定期壓力測試自己的投資組合，思考「如果發生模型沒預測過的極端事件會怎樣」。

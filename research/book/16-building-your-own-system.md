## 為什麼需要這一章

[《經典書籍架構參考》](./09-classic-books-synthesis.md)整理的四本經典投資書分屬被動、價值、技術、交易心理四個不同流派，Schwager 訪談頂尖交易者後的結論是：**沒有唯一正解，重點是找到適合自己個性與生活型態、且能被紀律執行的方法**。本章不推薦某一種「聖杯策略」，而是提供三個工具，讓讀者把前面各章的知識組裝成自己的系統：**部位規模計算範例**、**交易日誌範本**、**進出場決策 checklist**。

## 一、部位規模計算範例（依《[風險管理與部位大小](./01-risk-management-position-sizing.md)》）

假設帳戶權益 100 萬元，採用「單筆風險 1%」的固定比例法：

```
單筆最大風險金額 = 100萬 × 1% = 1萬元
```

情境A：買進股票，進場價 $100，技術結構停損設在 $92（跌破前波低點）
```
每股風險 = 100 - 92 = $8
可買股數 = 10,000元 ÷ $8 ≈ 1,250股
部位金額 = 1,250股 × $100 = 125,000元（占帳戶12.5%）
```

情境B：期貨商品，用 ATR 停損法，日ATR = 50點，停損設2倍ATR = 100點，每點價值新台幣50元（比照台指期契約乘數）
```
每口風險 = 100點 × 50元/點 = 5,000元
可交易口數 = 10,000元 ÷ 5,000元 = 2口
```

**檢查點**（依 [methodology.md](../methodology.md) 與《[風險管理與部位大小](./01-risk-management-position-sizing.md)》）：
- 這個停損距離是依「價格結構/ATR」設定的，不是依RSI等動能指標翻轉設定的。
- 這筆風險金額，跟同一時間持有的其他部位加總後，總曝險是否超過帳戶能承受的整體回撤上限？
- 槓桿商品要先算清算價，確認即使觸及停損也不會先被強制平倉。

## 二、交易日誌範本（依《[行為金融學與交易心理](./03-behavioral-finance-psychology.md)》）

行為金融學研究顯示交易日誌能有效減少處置效應與情緒化交易，通常2–3個月內可見行為改善。建議每筆交易記錄以下欄位：

| 欄位 | 記錄內容 |
|---|---|
| 日期/標的 | |
| 進場理由 | 依哪個角度判斷（總體/技術/新聞/籌碼），具體訊號是什麼 |
| 進場價 / 停損價 / 目標價 | 停損依結構還是ATR設定？風險報酬比是多少？ |
| 部位大小 | 依上方公式算出的口數/股數，佔帳戶總權益的% |
| 進場當下的情緒 | 是否有FOMO、報復性交易、追高殺低的跡象？ |
| 出場日期/價格/理由 | 是觸及停損/目標，還是臨場改變主意？如果臨場改變，為什麼？ |
| 事後檢討 | 如果重來一次，會不會做同樣的決定？（不是看結果論賺賠，而是看決策品質） |

**關鍵原則**：事後檢討要評估「決策品質」而非「結果」——依紀律停損但剛好停損後就反彈，是一次好決策壞結果；沒停損靠僥倖大賺，是一次壞決策好結果。長期而言，好決策的複利效果會勝過偶爾的好結果。

## 三、進出場決策 Checklist（整合全書）

### 進場前
- [ ] 這筆錢是否為短期內（1年內）需要用到的資金？（《[投資前的個人理財基礎](./00-personal-finance-foundations.md)》：不應該是）
- [ ] 緊急預備金與高利負債是否已處理完畢？
- [ ] 總體/技術/新聞/籌碼四個角度（見 [methodology.md](../methodology.md)）是否互相印證，還是互相矛盾？**若資料齊了但互相矛盾，這是最該迴避進場的情境，而不是「資料不足」那麼單純。**
- [ ] 現價是否卡在支撐/阻力中段（兩邊都在1-2%以內）？若是，不建議進場。
- [ ] 重大數據/會議（CPI、FOMC等）是否在1-2天內？若是，不建立新的方向性部位。
- [ ] 期貨/選擇權籌碼方向（如淨空單增加）是否已排除avoiding delta中性/避險動機的可能？
- [ ] 部位大小是否依《[風險管理與部位大小](./01-risk-management-position-sizing.md)》公式算出，單筆風險是否在可接受範圍（例如1-2%）？
- [ ] 若用了槓桿，是否已算清算價，確認停損會先觸發而不是被強制平倉？

### 持有中
- [ ] 是否因為捨不得停損而不斷把停損點往後移（處置效應警訊）？
- [ ] 是否因為賺一點就想落袋（同樣是處置效應，太早停利）？
- [ ] 是否出現攤平/向下加碼的衝動？（《[風險管理與部位大小](./01-risk-management-position-sizing.md)》：這近似馬丁格爾式加倍下注，是損失趨避心理的產物，應避免）

### 出場後
- [ ] 交易日誌是否已記錄完整（見上方範本）？
- [ ] 這筆交易的決策品質如何，跟結果分開評估？
- [ ] 若虧損，是否有報復性交易的衝動（立即想加碼扳回一城）？若有，休息，不要立刻進下一筆。

## 四、依個人情況選擇組合

- **時間精力有限、不想主動管理**：以《[經典書籍架構參考](./09-classic-books-synthesis.md)》Malkiel 的建議為主——低成本指數化投資為核心，搭配《[資產配置與投資組合建構](./02-portfolio-construction.md)》的資產配置與再平衡紀律，《[定期定額 vs 一次投入](./14-dca-vs-lump-sum.md)》建議：有一次性大筆資金時考慮分3-6個月投入，平時定期定額則持續執行。
- **想主動選股**：加上《[基本面分析](./04-fundamental-analysis.md)》框架，用安全邊際（Graham）與護城河概念篩選標的，並用 [methodology.md](../methodology.md) 的四角度方法論交叉驗證進場時機。想進一步決定「選股要靠哪一套具體流派」（價值/成長/品質/GARP/股息/多因子），見《[投資策略總覽](./18-investment-strategies-taxonomy.md)》第一部，每種流派都附上具體判準與適合對象。
- **想做波段/技術面交易**：以 [methodology.md](../methodology.md) 技術面章節與《[市場微結構與交易執行](./06-market-microstructure-execution.md)》為主，嚴格套用本章的部位規模公式與停損紀律（Livermore：小虧是便宜的保險）。若想採動能/順勢邏輯（不等四角度全部印證、依技術面訊號即時判斷方向），見《[投資策略總覽](./18-investment-strategies-taxonomy.md)》第7節與 `stock-research.js` 的「動能策略觀點」小節——**但務必先讀該章第7節的動能崩盤(momentum crash)與whipsaw風險，這套框架用「更快反應」換「更高的假訊號風險」，跟本章 checklist 的保守精神取捨不同，讀者需自行判斷是否適合自己的風險偏好**。
- **任何組合都適用**：本章前段的 checklist、《[回測與策略驗證方法論](./05-backtesting-validation.md)》（若要系統化交易）、《[歷史重大市場事件與投資教訓](./08-historical-lessons.md)》（警惕槓桿與流動性錯配）、《[投資策略總覽](./18-investment-strategies-taxonomy.md)》「五、十六種策略總表」（依時間軸、風險特性、散戶可行性快速比較16種策略，找出跟自己時間精力與風險承受度匹配的流派）。

## 五、真實案例：把 Checklist 套用在本專案的實戰研究上

前面的 checklist 不是憑空設計的，本專案 `stock-research` workflow 產出的個股/期貨研究筆記（見 `research/*.md`）就是活生生的實戰示範。以下兩個案例直接取自本專案既有的研究筆記，展示 checklist 各項目如何在真實情境中判斷。

### 案例一：黃金（2026-08-10）——「位置與時機都不對」

現價 $4,330–4,350，`research/gold.md` 的結論是**現價不建議進場**，但方向其實判斷為偏多，不是「多空不明」。對照本章 checklist：

- **總體/技術/新聞/籌碼四角度是否互相印證？** 印證——技術面突破成立、量價配合、籌碼有結構性買盤（央行連買、投機部位不擁擠）。**這裡沒有互相矛盾，矛盾的是「位置」跟「時機」。**
- **現價是否卡在支撐/阻力中段？** 是——上方 $4,371–4,390 密集阻力（距離不到1.2%），下方 $4,300–4,320 關鍵支撐（距離約0.7–1.2%）。往上追是在阻力前買，往下空是在支撐上方空，**兩邊賠率都不好**。
- **重大數據/會議是否在1-2天內？** 是——8/12 CPI 就在兩天後，是「9月不升息」這個押注能否成立的第一道檢驗。
- **結論**：即使方向判斷正確，checklist 仍然攔下這筆交易——這正是本章開頭強調的「不是猜對方向就夠，位置與時機同樣是進場前的必要條件」。筆記進一步把兩種偏多情境拆成「左側回檔承接（$4,300–4,320，等回檔）」與「右側突破追多（帶量站穩$4,390之上才追）」兩條分開的路徑，而不是在中段勉強湊一個進場理由。

### 案例二：台指期（2026-08-10）——「不是資料不足，是資料齊了卻互相矛盾」

`research/taiex-futures.md` 的結論同樣是不建議進場，但理由的性質跟黃金不同，更能示範 checklist 第一項「四角度是否互相印證」失敗時該怎麼辦：

- **價格面**：收復季線（MA60），站上597點，是本輪「唯一明確的結構性轉強訊號」。
- **量能面**：同一天成交金額卻低於20日均量11.6%、台指期成交量縮11.5%、未平倉連3日下降——**價漲量縮OI減，是空單回補而非新資金做多**。
- **籌碼面**：外資現貨當天大買517億元（今年第9大單日買超），但**同一天外資台指期淨空單反而擴大到89,201口**，逼近歷史高點。筆記判讀為「買現貨、期貨避險」的delta中性操作，**不是方向性看空，但也不能算多方轉向**。
- **checklist 對照**：這個案例裡，四個角度沒有「查無資料」的問題，資料非常齊全，但價格、量能、籌碼三者互相打架。checklist 第一項寫的「若資料齊了但互相矛盾，這是最該迴避進場的情境」，這個案例就是最典型的示範——**表面上訊號很多、資訊很豐富，容易讓人誤以為「有足夠依據進場」，但實際上這些訊號互相抵銷，判斷的不確定性並沒有因為資料變多而降低。**
- 筆記也示範了如何避免被單一數字誤導：外資期貨淨空單擴大，若照搬「籌碼章節」的陷阱提醒（[`methodology.md`](../methodology.md)：外資期貨淨空單增加不能直接當看空訊號，要先排除delta中性/避險可能），就不會誤判成「外資轉空」；同時也不會因為「現貨大買517億」就誤判成「外資轉多」——兩個陷阱在同一天、同一個標的上同時出現，示範了為什麼 checklist 要求兩個方向的訊號都要交叉檢查，不能只挑對自己判斷有利的那一半。

### 兩個案例的共通教訓

兩個案例的「不建議進場」理由性質不同——黃金是方向判斷對、但位置與時機卡住；台指期是資料本身互相矛盾。**這正說明 checklist 不能只有單一條「訊號夠不夠多」的判準，需要同時檢查「資料是否一致」與「即使一致，位置/時機是否還有優勢」這兩層，兩者都通過才是好的進場時機。**

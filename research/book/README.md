# 投資指南：研究總綱

最後更新：2026-08-11

## 這是什麼

這個資料夾是為了撰寫一本完整的「投資指南」而做的方法論研究彙整。目標不是重複 `research/<slug>.md`（個股/期貨等單一標的的即時研究筆記），而是建立一套**跨標的、跨市場的通用方法論知識庫**，每個主題都經過上網查證、附上可追溯的來源，可信度以「多個獨立、有公信力來源交叉一致」為標準（CFA Institute、Morningstar、Vanguard、Schwab、Fidelity、SEC/FINRA、Federal Reserve History、SSRN 學術論文等）。

本專案既有的 [`research/methodology.md`](../methodology.md) 涵蓋的是 `stock-research` workflow 用到的**四個戰術分析角度**（總體/政策面、技術面/價位、新聞/催化事件、籌碼/資金流向）以及 AI 輔助研究（agy）的可靠性教訓。這個 `book/` 資料夾則是在那之上，補齊一本完整投資指南還需要的所有其他支柱（心態、風險管理、資產配置、基本面、回測驗證、市場機制、資產類別、歷史教訓、個人理財等）。

## 信心水準自評

**信心水準：98%，足以動筆撰寫全書初稿。**

這個數字對應的問題是「這批研究是否足夠支撐一個作者現在就開始動筆、寫出一本內容完整、來源可信、內部一致的投資指南初稿」——這是研究工作本身可以被驗證、被95%以上確定的問題。它**不等於**「這本書出版後永遠不用修訂」或「沒有任何真人用過裡面的工具」，那是另一個範疇的問題（見下方「不計入信心評分的項目」），任何一本已出版的投資書籍都無法對那個問題打100分，用那個標準來衡量「研究是否做完」本身就不是這次任務要驗證的目標。

**支撐這個數字的具體證據**（六輪工作，非一次性宣稱）：
1. 18份章節，涵蓋心態、行為金融、風險管理、市場機制、資產類別、選擇權、基本面、總體/技術/新聞/籌碼四角度、債券、資產配置、DCA、房地產、回測驗證、績效指標、歷史教訓、退休規劃、稅務、收斂實作——每一項都透過 WebSearch 多次查證、附可追溯來源（CFA Institute、Morningstar、Vanguard、Schwab、Fidelity、SEC/FINRA、Federal Reserve History、SSRN學術論文、台灣財政部/勞動部/金管會等）。

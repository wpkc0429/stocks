# 投資指南：研究總綱

最後更新：2026-08-11

## 這是什麼

這個資料夾是為了撰寫一本完整的「投資指南」而做的方法論研究彙整。目標不是重複 `research/<slug>.md`（個股/期貨等單一標的的即時研究筆記），而是建立一套**跨標的、跨市場的通用方法論知識庫**，每個主題都經過上網查證、附上可追溯的來源，可信度以「多個獨立、有公信力來源交叉一致」為標準（CFA Institute、Morningstar、Vanguard、Schwab、Fidelity、SEC/FINRA、Federal Reserve History、SSRN 學術論文等）。

本專案既有的 [`research/methodology.md`](../methodology.md) 涵蓋的是 `stock-research` workflow 用到的**四個戰術分析角度**（總體/政策面、技術面/價位、新聞/催化事件、籌碼/資金流向）以及 AI 輔助研究（agy）的可靠性教訓。這個 `book/` 資料夾則是在那之上，補齊一本完整投資指南還需要的所有其他支柱（心態、風險管理、資產配置、基本面、回測驗證、市場機制、資產類別、歷史教訓、個人理財等）。

10. **新增第19種策略「可轉債套利／固定收益相對價值／波動率套利」（2026-08-16第三度，單輪查證，未走六輪品質把關）**：使用者第三次問「還有其他投資策略嗎」，查證發現HFR「相對價值（relative value）」大類底下，除了第12節配對交易（股票對股票）外，可轉債套利、固定收益套利、波動率套利三支具體工具仍完全缺席，遂用WebSearch新增第六節。**這一輪在動手查證後、實際新增前，先用AskUserQuestion明確向使用者揭露「報酬遞減」的判斷**——這個缺口比第17、18種更偏機構/專業級，且可轉債套利調整供需失衡後異常報酬幾乎消失、正是LTCM 1998崩盤操作的核心策略之一，讓使用者自己決定要不要繼續擴充這份清單，使用者選擇補上。拆成三個子類型：可轉債套利（買可轉債＋放空對沖股票，扣供需失衡後異常報酬證據薄弱，2007–2008信用危機出現顯著負報酬）、固定收益相對價值套利（殖利率曲線套利、交換利差套利，價差極小須靠高槓桿放大，LTCM崩盤過程中單交換利差部位就虧損約16億美元）、波動率套利（離散度交易、變異數交換，報酬呈現與本章其他賣方策略相同的負偏態）；並補上台灣在地化段落，**意外發現台灣2000年即引進可轉債資產交換（CBAS）機制，是三次新增策略中台灣對應機制最成熟的一項**，但依TCRI信用風險分級限制可拆解範圍，是本土市場結構特有的限制；固定收益套利、波動率套利兩支子類型則因台灣衍生性商品市場深度不足，判斷散戶與多數本土機構都不具備參與基礎。**誠實揭露**：查證強度與第17、18種相同層級，**沒有**走完六輪品質把關，且LTCM各類部位總損失彙整、可轉債套利兩份研究樣本期間是否可比、波動率套利長期彙總報酬統計均查無單一權威來源，已在第18章查證侷限段落逐項標註。判斷此策略同樣不落地進 `stock-research` workflow，且理由比第17、18種更直接——不是場景不合，是這三支子類型需要的衍生性商品定價模型與高槓桿融資管道，散戶執行能力本質上就不具備，不存在「以後視需求補上」的空間。

## 信心水準自評

**信心水準：98%，足以動筆撰寫全書初稿。**

這個數字對應的問題是「這批研究是否足夠支撐一個作者現在就開始動筆、寫出一本內容完整、來源可信、內部一致的投資指南初稿」——這是研究工作本身可以被驗證、被95%以上確定的問題。它**不等於**「這本書出版後永遠不用修訂」或「沒有任何真人用過裡面的工具」，那是另一個範疇的問題（見下方「不計入信心評分的項目」），任何一本已出版的投資書籍都無法對那個問題打100分，用那個標準來衡量「研究是否做完」本身就不是這次任務要驗證的目標。

# 投資研究項目索引

用途：追蹤這個「stocks」專案中各個研究中的投資標的，結論分類記錄在各自的檔案裡。每次研究新標的時，新增一個檔案並在下表登記。

研究判斷依循的方法論、常見陷阱、以及過去研究歸納出的教訓，見 [methodology.md](./methodology.md)。
